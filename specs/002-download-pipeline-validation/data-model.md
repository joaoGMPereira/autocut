## Entities

### PipelineRun (updated)

Stored in `pipeline_runs` table. Two new columns added via migration v10.

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| `id` | INTEGER PK | auto | |
| `channel_id` | INTEGER FK nullable | | |
| `url` | TEXT | WAITING_URL advance | non-empty after advance |
| `mode` | TEXT | | default `'ai'` |
| `state` | TEXT | state machine | `WAITING_URL \| EXECUTING \| WAITING_MODE \| DONE \| ERROR \| CANCELLED` |
| `active_phase` | TEXT | state machine | `download \| transcribe \| …` |
| `error` | TEXT | | empty on success |
| `mode_config_json` | TEXT | | |
| `video_path` | TEXT | **download phase writes** | non-empty after successful download |
| `video_title` | TEXT | **download phase writes** *(NEW — migration v10)* | non-empty after successful download |
| `duration_sec` | INTEGER | **download phase writes** *(NEW — migration v10)* | seconds; > 0 after successful download |
| `transcript_path` | TEXT | transcribe phase writes | |
| `started_at` | INTEGER | creation | Unix ms |
| `finished_at` | INTEGER nullable | terminal state | Unix ms |

**Validation rules**:
- `video_path`, `video_title`, `duration_sec` MUST all be non-empty/non-zero before transitioning to `WAITING_MODE`
- If any are missing after download, run transitions to `ERROR`

**State transitions** (download phase scope):
```
WAITING_URL ──advance()──► EXECUTING (active_phase='download')
                                │
                         download goroutine runs
                                │
               ┌────────────────┴────────────────┐
               │ success                         │ failure / cancel
               ▼                                 ▼
        WAITING_MODE                      ERROR / CANCELLED
```

### PhaseContract

Defined in Go code (`pipeline/contracts.go`), not persisted to DB. Describes what each phase requires (inputs) and produces (outputs).

```go
type PhaseContract struct {
    Phase   PhaseID
    Inputs  []string  // DB column names that must be non-empty/non-zero
    Outputs []string  // DB column names this phase writes before exiting
}
```

**Download phase contract** (canonical declaration):
```go
var DownloadPhaseContract = PhaseContract{
    Phase:   PhaseDownload,
    Inputs:  []string{"url"},
    Outputs: []string{"video_path", "video_title", "duration_sec"},
}
```

### SSEEvent types (canonical)

All events emitted over `GET /api/pipeline/runs/{id}/stream`.

#### `state_changed`
```json
{
  "type": "state_changed",
  "data": { "run_id": 42, "state": "EXECUTING" }
}
```

#### `video_info`  *(once, after metadata extraction)*
```json
{
  "type": "video_info",
  "data": {
    "run_id": 42,
    "title": "My Video",
    "thumbnail_url": "https://...",
    "duration_sec": 3610
  }
}
```

#### `phase_progress`  *(≥ every 5 s during active download)*
```json
{
  "type": "phase_progress",
  "data": {
    "run_id": 42,
    "phase": "download",
    "percent_done": 45.2,
    "speed_kbs": 2560,
    "eta_sec": 28
  }
}
```
- `speed_kbs` and `eta_sec`: present in ≥ 80% of updates; absent in initial 0% and final 100%
- Both are `int` (rounded)

#### `error`
```json
{
  "type": "error",
  "data": { "run_id": 42, "state": "ERROR", "message": "download: exit status 1" }
}
```

#### `cancelled`
```json
{
  "type": "cancelled",
  "data": { "run_id": 42, "state": "CANCELLED" }
}
```

### DownloadProgressLine (internal, not persisted)

Parsed from each yt-dlp stdout line inside the streaming executor callback.

```go
type DownloadProgressLine struct {
    Percent  float64  // 0–100
    SpeedKbs int      // KB/s; 0 if not parsed
    EtaSec   int      // seconds remaining; 0 if not parsed
}
```

### PhaseID / RunState (string constants)

type RunState = string

const (
    StateWaitingURL          RunState = "WAITING_URL"

export interface PhaseProgressEvent {
  run_id: number
